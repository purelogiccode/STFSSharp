# Third-Party Notices

StfsSharp is an independent, clean-room MIT implementation of the Xbox 360
STFS and GOD/SVOD on-disk structures. It does not include or link any GPL code.

## XISOSharp

StfsSharp's initial reader implementation was extracted from
[XISOSharp](https://github.com/purelogiccode/XISOSharp), also MIT licensed and
maintained by the same author. The extracted code was reorganized behind a
standalone public API; no third-party code was introduced.

## Behaviour references

These projects were used as documentation/behaviour references only. No source
code is copied, ported or transliterated into StfsSharp.

- **XboxToolkit** (<https://github.com/XboxDev/XboxToolkit>) — GPL-3.0-only.
  Used as a behaviour reference for GOD/STFS reads. No code included.
- **Xbox360Convert** (<https://github.com/XboxDev/Xbox360Convert>) — no license
  file; links GPL code. Used only to understand GOD container layout and
  fragment naming. No code included.
- **xenia** (<https://github.com/xenia-project/xenia>) — used only as a layout
  reference for the SVOD hash-table interleave and fragment roll-over. No code
  included.
- **XeCrypt** (<https://github.com/emoose/XeCrypt>) — MIT. Used only to
  cross-check the STFS hash-tree structure. The implementation here is
  independent and was already present in XISOSharp.

## Format facts

The layout constants and algorithms were derived from observed on-disk
structures and the public format descriptions. The test suite uses only
synthetic fixtures generated by the repository's own fixture builder.
